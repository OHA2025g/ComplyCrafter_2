## 📋 Quick Reference

### **Run Services:**
```bash
cd ops
docker-compose up -d
```

### **Access Applications:**
- Frontend: http://localhost:4200
- Backend API: http://localhost:8100
- API Docs: http://localhost:8100/docs
- Database: localhost:5432

### **Run Tests:**
```bash
./scripts/quick_smoke_test.sh
./scripts/test_all_62_forms_complete.sh
```
